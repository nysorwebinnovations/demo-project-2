# 🛒  CeylonCart Studio Modern Grocery CMS Dashboard

An interactive, localized Admin Dashboard designed for supermarket inventory management, sales tracking, and order fulfillment in Sri Lanka.

[![Live Demo](https://img.shields.io/badge/Live_Demo-View_Dashboard-f59e0b?style=for-the-badge)](https://demo-project-2-nysor.vercel.app/)

---

## 📖 Overview
CeylonCart Studio Admin provides store managers with real-time operational oversight—from monitoring fresh produce inventory levels to tracking daily delivery trends across major Sri Lankan hubs.

## ✨ Key Features
- **Real-Time Analytics:** Sales trends, order completion metrics, and revenue charts using Recharts.
- **Inventory Management System:** Low-stock badges, stock status filters, SKU tracking, and LKR pricing.
- **Order Tracking Table:** Filterable grid displaying customer names, Sri Lankan locations (Colombo, Kandy, Galle), and live delivery stages.
- **Localized Grocery Catalog:** Pre-populated with popular local brands and fresh produce items.

## 🛠️ Tech Stack
- **Frontend:** React, TypeScript
- **Styling:** Tailwind CSS (Custom Hex Accent: #FBB917 & #DEB887)
- **Charts:** Recharts / Dynamic SVG Analytics Components
- **Deployment:** Vercel / Netlify
